## Open source

### [InstinctFlash](https://github.com/General-Instinct/InstinctFlash)

**High-performance inference for robotics models.**

A serving framework supporting eight frontier robotics model families, optimized for real-time inference on NVIDIA GPUs and Jetson hardware.

`AGPL-3.0` · [Repository →](https://github.com/General-Instinct/InstinctFlash)

### [InstinctRazor](https://github.com/General-Instinct/InstinctRazor)

**Efficient model compression and quantization.**

Sub-4-bit quantization and on-policy recovery for Hugging Face models. The open-source framework behind InstinctCompress.

`Apache-2.0` · [Repository →](https://github.com/General-Instinct/InstinctRazor)
